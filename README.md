# Ecosistema de Automatización IA para una consultora de pymes
Entrega Final · Coderhouse · IA Automation · Karen Videla

Pipeline de contenido que redacta borradores de LinkedIn con IA y RAG,
espera la aprobación de una persona y recién entonces envía el contenido a Slack.

## Contenido
- Entrega_Final_Karen_Videla_Ecosistema_IA.pdf: diagrama de arquitectura,
  manual de datos, matriz de costos y documento de seguridad y resiliencia.
- workflow-01-generacion-contenido-rag.json: flujo de generación (n8n).
- workflow-02-publicacion-hitl-slack.json: flujo de publicación con aprobación (n8n).
- Capturas de evidencia del flujo, las pruebas y el dashboard.
